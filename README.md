# Deforestation & Land Use Change Monitoring

Time-series satellite imagery analysis platform for detecting deforestation, illegal logging, and land encroachment across Cross River (Nigeria), Congo Basin, Cameroon Highlands, and West Africa. Generates real-time alerts for forest rangers with driver attribution and severity classification.

---

## Features

- 9-year time-series (2015–2023) across 6 forest regions
- Random Forest alert classifier with class balancing
- Interactive area chart of annual forest cover loss trends
- Region selector for multi-year trend analysis
- Real-time alert detection with severity scoring

---

## Setup & Run

```bash
git clone https://github.com/Momahmoses/deforestation-monitoring.git
cd deforestation-monitoring
pip install -r requirements.txt
streamlit run streamlit_app.py
```
